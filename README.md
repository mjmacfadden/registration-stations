
## Class-day setup (worksheet + QR codes)

**Directions:** every station shows a **"How this station works"** box directly under the top bar, with numbered steps (start timer → phases → write answers on the worksheet handout → next station). Steps live in each station's `window.STATION_GUIDE`; the panel is rendered by `assets/station-guide.js`.

**Worksheet (no backend):** the teacher hands out one Station Worksheet per student (source Google Doc:
https://docs.google.com/document/d/1T4CoDCfOeXmaG8HfRkp6mB3KqLw1KKSL0WY6ReUTmXg/edit?usp=drivesdk). Stations only say to write answers on the handout; they don't link the Doc or ask students to make copies.

**QR posters:** `assets/station-qr-codes.pdf` — 8 letter-size pages: Station Menu and the 7 stations. Print and post one at each station.
- QRs point to GitHub Pages: `https://mjmacfadden.github.io/registration-stations/<station>/`. Pages builds from `main`, so merge this branch before class for the new directions to be live.
- Regenerate: `python3 -m venv .venv && .venv/bin/pip install qrcode reportlab pillow && .venv/bin/python scripts/make_qr_pdf.py`

**On-screen QR codes:** on the hub, click **Settings** (top right) to open a modal with every station's QR code and title. Click **Print** to print just the codes (3 per row). The QR images are in `assets/qr/` and are regenerated by the same `scripts/make_qr_pdf.py`.
